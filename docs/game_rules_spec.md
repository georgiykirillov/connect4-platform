\## 1. Вариации самой игры

1.1 Изменение гравитации. Раз в несколько ходов гравитация может меняться на вниз, влево, вправо, вверх

1.2 Twist \& Turrn. После хода можно перевернуть колонну в которую ходил

1.3 Pop out. Вместо своего хода в какой-то колонне можно "вытолкнуть" свою фишку если она в самом низу

1.4 Камни. Некоторые клетки поля заняты непадающими камнями, которые не считаются никому в четверки

1.5 Порталы? Пока сомнительно

\## 2. Идея реализации поля

2.1. Стандартные размеры поля:

&#x20;  - Количество колонок (ширина, $W$): `?`

&#x20;  - Количество строк (высота, $H$): `?`

2.2. Система координат:

&#x20;  - Где находится точка `(0, 0)`: скорее сверху-слева

&#x20;  - Как обозначаются координаты ячейки: `(x, y)`

2.3. Кодирование содержимого ячейки:

&#x20;  - Какими значениями (числа, строки или Enum) мы обозначаем:

&#x20;    - Пустую ячейку: `0`

&#x20;    - Фишку первого игрока: `r`

&#x20;    - Фишку второго игрока: `b`

2.4 Между ячейками должны быть условные перегородки, для реализации некоторых дополнительных правил
